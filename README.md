# ☕ JAVA-PROGRAMMING

Welcome to my personal repository dedicated to mastering **Data Structures, Algorithms (DSA)**, and core Java concepts. This repository tracks my journey of problem-solving and building a strong programming foundation using Java.

## 🚀 Repository Structure

The code is cleanly organized into specialized folders covering algorithmic paradigms and structural data types:

```text
JAVA-PROGRAMMING/
├── DSA/
│   └── src/
│       ├── Basics/              # Core foundations & syntax operations
│       ├── If_Else/             # Conditional logic implementations
│       ├── Loop/                # Iterative code blocks & mechanics
│       ├── Methods/             # Functions, scoping & value passing
│       ├── Pattern/             # Geometric logic printing patterns
│       ├── Array/               # Multi-pointer approaches & vector mutations
│       ├── Basic_Sorting/       # Selection, Bubble, and Insertion sorts
│       ├── Binary_Search/       # Logarithmic dividing searches & bounds
│       ├── Cyclic_Sort/         # In-place linear array index mapping
│       ├── Bit_Manipulation/    # Binary masking & bitwise computations
│       ├── Merge_Sort/          # Divide-and-conquer sorting mechanics
│       ├── Recursion/           # Self-referential algorithms & trees
│       ├── Heap/                # Priority queue models & streaming sorting
│       ├── DP/                  # Dynamic programming & functional state spaces
│       └── HashMap/             # Hashing lookups, frequency maps & strings
└── .gitignore                   # Workspace cleaning configuration
```

## 💻 How to Run Locally

To explore or run any of these files on your local machine, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/rishir143/JAVA-PROGRAMMING.git
   ```
2. Open the root folder inside **IntelliJ IDEA** or any Java-supported editor.
3. Navigate to `DSA/src/` to explore code files.
4. Select any source file containing a `main` execution method and click **Run**.
